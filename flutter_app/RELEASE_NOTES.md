## 静笺 1.8.2

1.8 系列的补完版：把旧版剩下的 5 项功能都迁了过来，并修了几处问题。

### 新增：图床上传
- 「设置 → 图床」支持 SM.MS、Imgur、PicGo（本机服务）、兰空 Lsky、自定义接口，以及 GitHub / Gitee 仓库图床。
- 配置项与旧版一致，可以导入 PicGo / Typora 的配置，也可以先「测试上传」。
- 插入或粘贴图片时自动上传，可选「同时保留本地副本」。上传失败会退回为本地图片，不会丢图。
- 支持粘贴图片：桌面端 Ctrl+V，Android 可用输入法插图，格式栏里也有「粘贴图片」按钮。

### 新增：博客平台发布
- 「设置 → 博客平台」支持 WordPress、Typecho、Halo、Ghost、语雀，和原来的 Git 博客并列。
- 每个平台都可以单独开关，也可以先测试连接。
- 发布时勾选要发到哪些平台，会记住上次的选择。再次发布同一篇会更新原文章，不会重复创建。
- 文中的本地图片会先传到图床。
- 菜单里新增「从博客拉回文章」。

### 新增：多人实时协作（仅限静笺同步服务器）
- 只有在「设置 → 同步」选择「静笺服务器」（项目自带的 sync-server），并且能用 Token 连上时，才会出现「多人协作」和「加入协作」。用 WebDAV、文件夹、对象存储或关闭同步时，这两个入口不显示。
- 不使用 P2P、WebRTC 或任何公共信令服务。编辑内容只经过你自己的同步服务器。
- 在编辑器菜单选「多人协作」可以发起协作，服务器会生成 6 位房间码。连接同一服务器的设备（安卓、电脑、网页版）在「加入协作」里输入房间码即可一起编辑。
- 多人同时修改时，由服务器统一排序并自动合并（OT 算法），并显示在线成员。发起人结束协作后，房间随之关闭。
- 中文输入法组字期间不发送内容，不会打断输入。未开启协作时，编辑器的行为与之前完全一样。
- 服务端：sync-server 新增 WebSocket 接口 `/api/collab`（使用同一个 JINGJIAN_TOKEN），`/health` 会返回 `collab: 2`，不需要新增依赖。需要更新服务端才能用协作。如果前面有反向代理，要放行 WebSocket（Upgrade）。

### 新增：AZW3 / KF8 电子书导入
- 现在可以导入 AZW3（KF8），包括章节、图片和书名作者等信息。

### 新增：侧栏宽度可拖动
- 桌面和平板上，侧栏、笔记列表与编辑区之间的分隔线可以拖动调整宽度。双击分隔线恢复默认宽度。
- 宽度会保存，重启后不变。

### 修复
- MOBI 导入读错文件头位置，导致书名和图片不对。
- Git 博客选 Gitee 时请求地址写错。
- Android 无法连接 http 地址（如 PicGo 本机服务、内网的同步服务器）。
- sync-server 的 Dockerfile 少复制了 note-file.mjs，镜像无法启动。
- macOS 正式版没有网络权限。

## 静笺 1.8.1

1.8 系列的补完版，不是新大版本：旧版（React/Capacitor/Electron）的功能都已迁到 Flutter 重构版里，另外加了 OLED 纯黑模式。

### 新增：OLED 纯黑
- 在「菜单 → OLED 纯黑」或「设置 → 外观」里开启，默认关闭。
- 只在深色主题下生效（墨夜、GitHub 深色、跟随系统且系统为深色）。
- 开启后背景、编辑区、预览、侧栏和对话框都用 #000000。
- 边框保留淡灰色（#2A2A2A），各区域仍能分清。
- Mermaid 图、公式区域和 Android 状态栏/导航栏也一起变黑。
- 设置会保存，重启后不变。

### 外观
- 主题：跟随系统、宣纸、墨夜、GitHub、GitHub 深色。
- 编辑器字体：宋体、黑体、等宽。字号：小、中、大、特大。

### 编辑器
- 格式工具栏：粗体、斜体、删除线、代码、标题、列表、待办、引用、链接、[[双链]]、图片、表格、公式、Mermaid、分割线。
- 查找替换：支持区分大小写、正则和 $1 分组引用。
- 大纲跳转、字数统计、双链/反向链接/未链接的提及。
- 预览中点 [[双链]] 可以跳转；目标笔记不存在时可直接创建。
- 预览能显示本地图片和表格；行内公式不再把段落拆成多行。
- 快捷键：Ctrl/⌘ + B / I / K / F / H / E / S / N / P。
- 可切换为纯文本笔记。

### 阅读与朗读
- 电子书章节可上一章/下一章，可在光标处拆分章节，也可与下一章合并。
- 朗读可设置语速和语种，可开启「读完本章接着读下一章」。

### 导入与导出
- 新增 MOBI/PRC/AZW 导入（PalmDoc 和 HUFF/CDIC 压缩）和 FB2 导入。
- EPUB 导入时一并导入图片和封面。
- 新增导入 Markdown、TXT 和 ZIP（含 images/ 文件夹）。
- 新增导出 PDF、EPUB 和 ZIP。也可以整本书导出 EPUB，或导出整个文件夹。
- 新增打印和存为 PDF。

### 整理
- 排序：修改时间、创建时间、标题、最近打开。星标笔记置顶。
- 新增星标筛选和 #标签 筛选。
- 新建笔记时可选模板：空白、日记、会议、博客文章、待办。
- 快速打开：Ctrl+P。
- 文件夹可新建子文件夹、重命名/移动、导出、删除（笔记移到回收站）。

### 同步
- 图片随笔记一起同步，与旧版的 `%%JINGJIAN-IMAGES%%` 格式互通。
- 修复：服务器不返回 charset 时，同步下来的中文会乱码。
- 新增同步冲突对话框，可选「用本机」「用云端」或「两份都保留」。

### 暂未迁移
- 图床上传（SM.MS、Imgur、PicGo、兰空等）。
- WordPress、Typecho、Halo、Ghost、语雀发布。目前只支持 Git 博客。
- 多人实时协作（P2P）。
- AZW3/KF8 格式的电子书。
- PDF 直接生成只支持 Android、iOS 和 macOS。其他平台请导出 HTML 后用浏览器「打印为 PDF」。
